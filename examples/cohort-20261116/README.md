# 规模化成对评测

最新的固定规模统计见[200 组前后对照](comparison.md)。

52 个全新 kind 集群分别注入 OOM、存活探针重启、镜像拉取和 CPU 调度失败，得到 208 个故障现场。每个现场拆成完整 / 遮蔽一对，同一对交给三种策略。按注入类别和参考证据确认完整快照已形成后才评分。

| Qwen2.5 1.5B 对照 | 完整侧带证据命中 | 遮蔽侧拒答 | 成对通过 | 平均模型调用 |
|---|---:|---:|---:|---:|
| 旧流程 | 11/208 | 15/208 | 0/208 | 5.73 |
| 模型选取证顺序 + 规则校验 | 208/208 | 208/208 | 208/208 | 5.92 |
| 固定顺序 + 相同校验 | 208/208 | 208/208 | 208/208 | 0 |

固定时间采样另用 8 个集群、224 个唯一 Pod UID。每集群创建 28 个 Pod，等待 90 秒后逐个采集，固定顺序对照在 223/224 对上通过，有 1 个 OOM 样本返回证据不足。每种故障 56 个样本，四类均来自实验模板。额外 16 个手工构造的完整现场通过 12 个；首次镜像拉取错误、仓库镜像缺失、调度内存不足和污点限制四例未识别。模型与规则的可推广性仍需其他故障类型验证。
